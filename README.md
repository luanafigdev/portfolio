# Portfólio — Luana Figueiredo

Site profissional de apresentação, projetos e contato. Desenvolvido com HTML, CSS e JavaScript.

- Mantido o destaque do Universo de Luana e os links de contato.
- Incluídos arquivos visuais da apresentação dos projetos e imagem de fallback da versão antiga da Flor de Açúcar.

## Publicação

O site não usa etapa de build. Para publicar no GitHub Pages, copie o conteúdo da pasta do projeto para a raiz do repositório `luanafigdev/portfolio`, preservando a pasta `.git`. Depois, registre as mudanças e envie para a branch `main`.

```powershell
git add .
git commit -m "Atualiza portfolio com projetos publicados"
git push origin main
```

O endereço do site é `https://luanafigdev.github.io/portfolio/`.

## Estrutura

- `index.html`: conteúdo e navegação.
- `style.css`: layout, estilos e responsividade.
- `script.js`: menu, efeitos de entrada e fallback da imagem antiga.
- `assets/`: imagens e artes dos projetos.
